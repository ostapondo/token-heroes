# Concept boards

Design boards from the first design pass, kept as the visual reference for the game and
the future README. Each `.dc.html` file is one artboard of the canvas at
https://claude.ai/artifact/DhenU2wwiMAgLghoE6MAYE and needs that canvas's runtime to render.

| Board | Shows |
|---|---|
| `Main.dc.html` | Fight screen: auto attacks, tap strike, ultimate, live level-ups, endless bosses |
| `Wipe.dc.html` | Party wiped, ten-second respawn, the fight starts again |
| `Heroes.dc.html` | Ten heroes: owned, hired with coins, unlocked by lifetime tokens |
| `Bosses.dc.html` | Thirty bosses: eight creatures across nine elements |
| `Bestiary.dc.html` | Boss weather close-up: lava, blizzard, storm, summoning ring |
| `Enemies.dc.html` | Twelve pack enemies, the stage rhythm, one sprite in every element |

`first-round/` holds the rejected first concepts (Ukrainian copy, purple accents) for
comparison.
